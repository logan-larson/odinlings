# Basic types

Odin's basic types include sized integers (`i8` to `i64`, `u8` to `u64`,
`int`, `uint`), floats (`f16`, `f32`, `f64`), `bool`, `rune` and `string`.
Odin never converts between them implicitly: you write the conversion, like
`f64(x)`. Literals such as `2` or `"hi"` are untyped constants that fit
wherever a compatible type is expected.

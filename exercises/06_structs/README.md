# Structs

A struct groups named fields into one type. Struct literals can name their
fields, and fields you leave out get their zero value. Structs are values, so
assigning one copies it. Odin has no methods: you write procedures that take
the struct as a parameter. `using` on a field lets you reach that field's own
fields directly.

# Pointers

A pointer `^T` holds the address of a value of type `T`. `&x` takes the
address of `x`, and `p^` reaches the value `p` points to. Passing a pointer
lets a procedure change the caller's variable. Fields of a struct are reached
through a pointer with a plain dot. A pointer that points nowhere is `nil`.

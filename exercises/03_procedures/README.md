# Procedures

Odin calls functions "procedures". They are declared like constants:
`name :: proc(params) -> results { ... }`. Procedures can return several
values, name their results, give parameters default values, and be called with
named arguments. Odin has no implicit overloading; instead, a procedure group
`proc{a, b}` explicitly lists the procedures that share a name.

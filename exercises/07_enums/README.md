# Enums

An enum is a type with a fixed set of named values. When the type is known,
values can be written with just a leading dot, like `.North`. A `switch` over
an enum must handle every value unless it is marked `#partial`. Enumerated
arrays `[Enum]T` hold one element per enum value.

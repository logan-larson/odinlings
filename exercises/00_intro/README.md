# Intro

These first exercises show how Odinlings works. Each exercise is a tiny Odin
program in its own directory. Odin treats a directory of `.odin` files as one
package, so every exercise is a complete program that you can also build and
run yourself:

```
odin run exercises/00_intro/intro2
```

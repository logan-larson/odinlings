# Control flow

Odin has `if`, `switch`, `defer`, `when` and a single loop keyword: `for`.
Conditions need no parentheses, but braces are required. `switch` cases don't
fall through unless you say `fallthrough`. Loops can be labeled so that
`break` and `continue` can target an outer loop. `defer` runs a statement when
the surrounding scope ends.
